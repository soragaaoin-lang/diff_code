## 読み方

- 左の「読む対象」でファイルを選ぶ。右の「説明」に変更内容と確認点を表示する。
- 中央の「ファイル全体」は Python ファイル単位のグラフ。円の大きさは定義数。緑が変更、白系が影響候補。選択対象を紫の輪で示す。
- 呼び出しが複数あるファイル間の線は一組の有向エッジにまとめる。同じファイル内の関係はファイル全体の画面には出さない。
- 「選択ファイルの関数」でファイル内の定義と直接つながる外部の定義を表示する。関数は一覧または右の「関数を読む」から選択できる。
- 「説明の根拠」を押すと該当定義の「コード・根拠」に移る。差分と Base/Head コードは折りたたんで表示する。
- 検索は左側の対象一覧を絞り込む。「すべて」で未変更のファイルも一覧に出す。
- 深さ1/2は解析済み呼び出しに対する影響候補の範囲。ファイルグラフや関数グラフの表示階層とは独立している。
- 960px以下では対象一覧を上部の横並びにする。620px以下ではグラフと説明を縦に並べる。
